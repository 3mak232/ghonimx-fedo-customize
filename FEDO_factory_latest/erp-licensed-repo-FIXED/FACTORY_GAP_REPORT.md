# تقرير فجوات FEDO للمصنع

**الحالة: عمل جزئي تجريبي، غير صالح للتشغيل الفعلي أو للترحيل إلى الإنتاج.** المرجع الملفات الموجودة في هذه النسخة، لا الأعداد أو أوصاف التسليم القديمة. لم يُفتح مشروع Supabase للعميل ولم يُغيّر.

| المجال | الحالة عند فحص الأصل | الدليل والفجوة |
|---|---|---|
| شراء، مبيعات، مرتجعات، مخزون، دفعات وقوائم أسعار | موجود ويحتاج تطويرًا | أصناف الفواتير والأوامر تشير إلى `products.id`. تتعامل مسارات FEDO مع SKU مستقل للتركيبة، لكن لا توجد شاشة اختيار تركيبة ولا تكامل مصنع مكتمل. `price_lists` موجودة. |
| وحدات القياس | موجود وجاهز كأساس | `units` و`products.unit_id`؛ لم نحدد وحدة قماش افتراضية. لا يعني ذلك وجود تحويلات مؤكدة لكل وحدات العميل. |
| التشغيلات | موجود ويحتاج تطويرًا | `inventory_lots` و`inventory_lot_balances` تمثل دفعات عامة وليس رولات منفردة بعرض أو بواقي وصرف فعلي. |
| رولات فعلية | غير موجود ويحتاج إضافة | أضيف تسجيل وصفي تجريبي لـ `factory_rolls` ببند فاتورة/استلام وبدون إضافة مخزون ثانية. **لا توجد حركات أو رصيد رول فعلي ولا تعامل مع الإلغاء والمرتجعات**. |
| تركيبات | غير موجود ويحتاج إضافة | ربط تجريبي بين منتج أساسي وSKU مستقل في `factory_variants`. لا توجد شاشة إدارة أو أسعار فندق أو منع بيع المنتج الأساسي أو تكامل تقارير تركيبات. |
| BOM وأمر تصنيع | موجود ويحتاج تطويرًا | `boms`, `bom_items`, `work_orders`; `complete_work_order` يستهلك المخطط كله ويستلم المنتج فورًا. لا يُستخدم للمصنع بهذا الشكل. |
| إنتاج جزئي وموافقة استلام وهالك وبواقي وتكلفة فعلية | غير موجود ويحتاج إضافة | لا توجد الدورة المطلوبة؛ لم تُنفّذ في هذه النسخة. القيود وإعادة البناء يلزم تعديلهما معًا. |
| مراحل قابلة للتهيئة | غير موجود ويحتاج إضافة | لا يوجد مسار إعداد وتنفيذ مراحل لكل تركيبة في التخصيص الحالي. |
| مصادر الطلب والشحن | موجود ويحتاج تطويرًا | أوامر البيع والتسليم الجزئي والتكاملات موجودة؛ لا يوجد في التخصيص سجل شحن وتحصيل أو تصنيف مصدر الطلب المطلوب. |
| صلاحيات | موجود ويحتاج تطويرًا | `has_perm` / `require_perm` مع دور ومجموعة مستخدم مخصصة؛ `create_work_order` و`complete_work_order` القديمة تكتفيان بفحص الدور. لا يوجد فصل موثّق مالك/مدير في أدوار الأصل. في Migration التجريبية أضيف `require_perm('mfg')` للدالتين؛ لم تُختبر كل الأدوار أو صلاحيات عمليات BOM بعد. |
| محاسبة | موجود ويحتاج تطويرًا | `rebuild_journal` يعيد بناء التصنيع من أوامر `Completed`، ويجب ألا يكرر أو يتجاهل قيود الدفعات. الاختبار القديم اصطدم بخطأ غموض متغير `code` في `create_manual_journal`. |
| الترخيص والنسخ الاحتياطي | موجود ويحتاج تحققًا | لم تمس الملفات. نسخة المصدر احتُفظ بها، لكنها ليست نسخة احتياطية من قاعدة بيانات العميل. يلزم استعادة نسخة حقيقية على staging والتحقق من جداول الإضافة في كل مسار backup/restore. |

## نتيجة الفحص الفعلي
تركيب الأساس في PostgreSQL 17 مع محاكاة Supabase نجح؛ ظهر 93 جدولًا في `public` من الأساس، ثم 96 بعد ثلاثة جداول تجريبية، وعدد الدوال النهائية يعتمد على تعريف العد وامتدادات PostgreSQL. اختبارات التثبيت المحلي ليست شهادة Supabase أو إنتاج. لم يجر استنساخ قاعدة العميل أو تغييرها. **تنبيه:** النسخة الأصلية تحتوي إعدادات بيئة قديمة؛ يجب ضبط URL والمفتاح العام فقط لبيئة الاختبار، وعدم نسخ أي أسرار إلى الواجهة.
