# قاعدة البيانات: ملف واحد

شغّل `ERP_BASE_CURRENT.sql` **مرة واحدة** على مشروع Supabase **فاضي** من SQL Editor.
ده فيه كل حاجة لحد آخر تحديث: الأساس (v1.74) + الموازنة (1.84) + المساهمين (1.93) + كل تحديثات الأمان (بما فيها القسم F).

ماتشغلش أي ملف تاني من هنا، ماعدا `LICENSE_MODULE.sql` (بعد الأساس، لوحدة الترخيص)، ماعدا `07-local-test/ERP_rls_audit_READ_ONLY.sql` (للقراءة بس، بعد التشغيل).

- `history/` للمرجع بس، مش للتشغيل.
- التحقق اللي عملناه على Postgres 16 محلي مع محاكاة لـ Supabase (`07-local-test/supabase_shim.sql`): الملف اتشغل بدون أي خطأ، والجداول والدوال والصلاحيات طلعت صح، وأول تسجيل بيبقى admin تلقائياً.
- لازم تتأكد على Supabase الحقيقي: بعد التشغيل، شغّل `ERP_rls_audit_READ_ONLY.sql` وشوف إن الفحوص الخمسة بتطلع صفر.
